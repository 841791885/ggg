## 执行原则

- 基础 CRUD 与业务骨架已全部落地；进阶点由学习者按清单亲手实现，AI 不代做。
- 开始某任务前，依据当前实际代码复核字段和接口，但不得随意削减最终业务目标。
- 每完成一个任务：删除代码中对应 TODO(PRD-xxx 进阶) 注释 → 更新本索引状态列和清单状态 → 跑 `go vet ./... && go test -race ./...`。
