## 执行原则

- 后续阶段文档是预规划，不代表现在就实现对应代码。
- 开始某阶段前，依据上一阶段的实际代码复核字段和接口，但不得随意削减最终业务目标。
- 当前只执行 PRD-001，不提前添加 MySQL、Redis 或订单占位代码。
- 每阶段通过自动化测试、手工验收和代码审查后更新状态。
